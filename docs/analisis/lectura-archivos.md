# Lectura de archivos

**Nombre del proceso:** Lectura de archivos.

**Objetivo:** Recuperar información persistida.

**Descripción:** El usuario elige la opción del menú, el sistema obtiene la información, aplica las validaciones y muestra el resultado. Si ocurre un error, informa al usuario y permite volver al menú.

**Datos de entrada:** Nombre de archivo JSON.

**Procesamiento:** Comprobar existencia; decodificar lista.

**Datos de salida:** Registros o lista vacía.

**Reglas de negocio:** Formato lista JSON.

**Validaciones y errores:** JSON corrupto, acceso denegado.
