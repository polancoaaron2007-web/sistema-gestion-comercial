# Generación de reportes

**Nombre del proceso:** Generación de reportes.

**Objetivo:** Calcular estadísticas desde datos almacenados.

**Descripción:** El usuario elige la opción del menú, el sistema obtiene la información, aplica las validaciones y muestra el resultado. Si ocurre un error, informa al usuario y permite volver al menú.

**Datos de entrada:** Productos, ventas y movimientos.

**Procesamiento:** Sumar ingresos, unidades, stock, valor y promedios.

**Datos de salida:** Reportes y matriz.

**Reglas de negocio:** No usar cifras fijas; promedios por mes.

**Validaciones y errores:** Datos corruptos, fechas inválidas.
