# Diagramas de flujo
Cada archivo `.mmd` contiene un diagrama Mermaid editable. En https://app.diagrams.net/ use **Insertar > Avanzado > Mermaid** y pegue su contenido; exporte a PNG o SVG para entregar imágenes si el docente las solicita. Los diagramas incluyen inicio/fin, entrada/salida, decisiones y procesos.
